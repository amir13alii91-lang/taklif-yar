# تکلیف‌یار
اپلیکیشن اندرویدی ثبت و مدیریت تکالیف مدرسه، با رابط فارسی و راست‌چین.

## ساخت APK با GitHub Actions
1. همهٔ محتویات این پوشه را (نه خود پوشهٔ اصلی و نه فایل ZIP) در ریشهٔ مخزن GitHub بارگذاری کنید.
2. مطمئن شوید مسیر `.github/workflows/build-apk.yml` هم بارگذاری شده باشد.
3. به تب **Actions** بروید و اجرای `Build تکلیف‌یار APK` را باز کنید.
4. پس از موفقیت، از بخش **Artifacts** فایل `taklif-yar-debug-apk` را دانلود کنید و ZIP آن را استخراج کنید.
5. فایل `app-debug.apk` را روی گوشی اندرویدی نصب کنید.

## پشتیبان‌گیری
در صفحهٔ «گزارش و پشتیبان»، می‌توانید از داده‌ها فایل JSON بگیرید و بعداً بازیابی کنید. داده‌های برنامه روی همان دستگاه ذخیره می‌شوند؛ حذف داده‌های برنامه یا حذف برنامه ممکن است آن‌ها را پاک کند.

## نیازمندی ساخت
Android SDK 35 و JDK 17؛ GitHub Actions این‌ها را برای ساخت آماده می‌کند.
