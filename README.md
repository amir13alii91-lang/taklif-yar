# تکلیف‌یار
اپلیکیشن اندرویدی فارسی برای مدیریت تکالیف مدرسه.

## بارگذاری در GitHub
محتویات این پوشه را مستقیماً در ریشه مخزن بارگذاری کنید؛ ساختار باید شامل `app/` و فایل‌های `settings.gradle` و `build.gradle` در ریشه باشد. فایل `.github/workflows/build-apk.yml` نیز باید در همین مسیر قرار گیرد.

## دریافت APK
بعد از بارگذاری، در تب Actions اجرای `Build تکلیف‌یار APK` را باز کنید. اگر موفق شد، فایل `taklif-yar-debug-apk` را از Artifacts دانلود و از حالت ZIP خارج کنید. خروجی `app-debug.apk` است.

پشتیبان‌گیری از داده‌های برنامه از داخل بخش «گزارش و پشتیبان» انجام می‌شود.
